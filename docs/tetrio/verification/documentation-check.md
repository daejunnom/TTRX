# 문서 검증 기록

검사일: 2026-09-12. 대상은 작업소의 초기 docs/ 분석 문서와 근거 JSON이다. 이 기록은 구현 전 문서 단계의 역사적 검사 결과이며 게임 재생·Rust·WASM·바이너리 코덱 테스트 결과가 아니다. 이후 `source-semantic` 구현 결과는 [변환기 검증 기록](../../ttrx/validation.md)을 본다.

## 일관성 검사

- 산출물 24개: Markdown 20개, JSON 4개. UTF-8 디코딩, 마지막 newline, 제목·제목 뒤 간격, trailing whitespace를 검사했다.
- 모든 상대 문서 링크가 docs/ 안의 존재하는 파일을 가리키는지 확인했다. 외부 웹 링크의 장기 접근 가능성은 이 검사에 포함하지 않는다.
- 옵션 JSON 173개, 분류 13개, catalog의 옵션 행 173개를 비교했다. 중복·누락 없이 일치하고 모든 분류의 담당 문서가 존재한다.
- 모든 옵션의 기본값이 존재하고 version 기본값은 11이다. noextrawidth의 정적 member 참조는 0개다. 구현·실행 검증 플래그는 모두 false다.
- 프리셋은 고유 이름 10개와 순서 있는 설정 530개다. 이 숫자를 커스텀 규칙 전체 개수로 해석하지 않는다.
- 표본은 2개, 합계 596,306 bytes와 7,539개 사건이다. 명시 옵션 합집합 57개, 미명시 기본 옵션 116개, 미지 옵션 키 0개다.
- IGE의 event/envelope frame 차이는 253개다. payload.frame이 있는 251개와 없는 26개를 구분했으며, 존재하는 251개는 모두 바깥 frame과 다르다.
- source manifest, options, fixture observations, presets의 공식 소스 SHA가 일치한다.
- 문서 작성 때 공식 소스를 다시 읽고 고정 SHA와 일치함을 확인한 뒤 옵션·프리셋 자료를 추출했다. 사용자 바인딩은 기본 객체의 실제 키를 재확인해 22개로 기록했다.

## 검사의 한계

자동 검사는 링크·구조·집계·목록 일치를 확인한다. 문서의 모든 동작 설명을 공식 클라이언트에서 실행해 입증하는 검사가 아니다. 구간별 정적 감사 결과를 문서에 옮기고 기존 표본·소스 해시·일부 경로를 재확인했으며, 서버 상수·규칙 확장·모드별 실행과 Rust 수치 동치는 미해결 상태로 유지했다.

원본 리플레이와 외부 참고 저장소는 수정하지 않았다. 이 문서 검사를 수행한 시점에는 작업소에 구현 코드, 패키지 설치 결과, 빌드 산출물 또는 `.ttrx` 실행 결과를 만들지 않았다.
